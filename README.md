# NOVA

VFX and compositing portfolio for **Altus Schultz**.

Live at **https://hertz-blip.github.io**

Hand-built multi-page site — HTML, CSS and vanilla JS, no framework and no
build step. Originally produced for FND005 at SAE Dubai.

## Structure

| Path | Contents |
|---|---|
| `index.html` | Home — hero video, work grid |
| `pages/` | About, Contact, and one page per project |
| `assets/css/style.css` | Core styles |
| `assets/css/effects.css` | Animations and transitions |
| `assets/js/script.js` | Bootloader, scroll-reveal, page transitions, lightbox, cursor |
| `assets/media/` | Stills and video per project |
